# Divisão de responsabilidades

Engenharia de dados entrega Parquets, contratos, partições, hashes, dicionário e verificadores. A equipe de modelagem executa baseline, modelos, validação cruzada, hiperparâmetros, métricas, calibração, limiar, análise de erros e equidade.

Nenhuma decisão de modelo, custo, benefício, capacidade ou limiar foi tomada nesta etapa.
