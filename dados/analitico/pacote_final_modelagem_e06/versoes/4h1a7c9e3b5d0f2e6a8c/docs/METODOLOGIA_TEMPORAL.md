# Metodologia temporal

A matriz usa a assinatura como momento da previsão. O resultado foi apurado pelo último snapshot observável até 31/12/2024; os preditores históricos são congelados na origem e não incorporam o próprio instrumento.

Treino: 2008–2019. Validação: 2020–2021. Teste: 2022–2023. Essas divisões não devem ser alteradas para aproximar prevalências. Qualquer transformação, imputação, codificação ou seleção deve ser ajustada somente no treino.

O teste permanece intocado para a decisão de hiperparâmetros. A equipe deve auditar a disponibilidade dos rótulos e a dependência por município antes da validação cruzada.
