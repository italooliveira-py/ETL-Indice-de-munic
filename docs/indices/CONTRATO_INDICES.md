# Contrato dos índices de contexto

Os produtos são índices descritivos anuais e relativos, não previsões de risco. O contrato publica os quatro índices aprovados, os subíndices PNCP, coberturas, quantidades válidas, faixas anuais, versão metodológica e metadados temporais.

`historico_execucao_transferegov` permanece nulo com `status_historico_execucao = indisponivel_dados_transferegov`. A ausência não penaliza nenhum índice.

O PNCP representa contexto de contratação pública e não comprova a execução material ou financeira dos projetos. A dimensão histórica de execução permanece indisponível até a integração temporalmente válida dos dados do Transferegov.

Os valores são retrospectivos e descritivos; faixas são definidas dentro de cada ano e valores de anos diferentes não constituem probabilidades diretamente comparáveis. Não há causalidade nem recomendação automática. Dados eleitorais foram adiados para versão posterior.

Próximos passos: integrar o histórico temporal do Transferegov; validar associação com desfechos maduros; avaliar contexto político somente em etapa posterior; revisar pesos após evidência empírica, sem ajustar pelo conjunto de teste.
